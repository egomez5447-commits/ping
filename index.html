Connect Ping

Ping needs a free Firebase project to carry messages between phones. Takes about five minutes, once.

  1. Go to console.firebase.google.com and tap Create a project. Any name. Skip Analytics.
  2. Open Build → Authentication → Get started, scroll to Anonymous, turn it on, and save.
  3. Open Build → Realtime Database → Create database. Choose Start in test mode.
  4. In Project settings → Your apps, tap the </> web icon, register the app, and copy the firebaseConfig block it shows you.
  5. Paste it below.

Firebase web keys are public by design — they identify your project, they don't unlock it. Your database rules are what protect the data.
