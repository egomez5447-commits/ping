# Build Royale

A Fortnite-style third-person battle royale you can play in the browser (Three.js, no build step).

Run it from a web server (ES modules don't load over `file://`):

    cd fortnite-clone && python3 -m http.server 8000   # open http://localhost:8000

Features: skydive + glider drop, 24 AI opponents, shrinking storm, chests, pickaxe harvesting,
rifle and shotgun, and building (walls / floors / ramps, ceilings by looking up).

Fan-made tribute; not affiliated with Epic Games.
